# Подключение Supabase

## 1. Создайте проект

Создайте проект Supabase и сохраните его URL. В настройках проекта скопируйте **Project URL** и публичный **anon / publishable key**.

В `supabase-config.js` вставьте значения:

```js
window.ALFA_SUPABASE_CONFIG = {
  url: "https://YOUR-PROJECT.supabase.co",
  anonKey: "YOUR-PUBLIC-ANON-KEY",
  adminLogins: [
    { username: "your-login", email: "YOUR-ADMIN-EMAIL" }
  ]
};
```

Публичный anon key предназначен для браузера. **Не помещайте в этот файл service_role key или секретный ключ**: они обходят ограничения доступа.

## 2. Создайте таблицы и хранилище

Откройте **SQL Editor** в Supabase, вставьте содержимое `supabase-setup.sql` и выполните его. Скрипт создаёт таблицы, ограничивает изменения данных администраторами, загружает начальные товары, цены и расписания, а также настраивает хранилище фотографий. Таблица `training_schedules` хранит занятия по направлениям бокса, борьбы и фитнеса. Если база была создана по предыдущей версии схемы, выполните обновлённый SQL повторно: он добавит таблицу расписаний и не перезапишет уже сохранённые значения.

## 3. Создайте учётную запись администратора

В **Authentication → Users** создайте пользователя с email и надёжным паролем. В `supabase-config.js` добавьте его логин и тот же email в массив `adminLogins`. Затем в SQL Editor добавьте пользователя в список администраторов, подставив email:

```sql
insert into public.admin_users (user_id)
select id from auth.users where email = 'YOUR-ADMIN-EMAIL'
on conflict (user_id) do nothing;
```

В форму управления входите по логину из `adminLogins` и паролю соответствующего пользователя Supabase. Для каждого дополнительного администратора создайте пользователя в **Authentication → Users**, добавьте `{ username: "нужный-логин", email: "EMAIL-АККАУНТА" }` в `adminLogins` и выполните SQL-запрос выше для его email. Кнопка «Выйти из аккаунта» завершает текущую сессию и позволяет войти под другим аккаунтом. Логины и email в `supabase-config.js` доступны посетителям сайта, поэтому не используйте секретные данные в качестве логина. Только пользователи из `admin_users` могут изменять цены, расписания, товары и фотографии. В панели управления откройте вкладку «Расписание», добавляйте и удаляйте занятия для бокса, борьбы и фитнеса, указывайте день, время, название тренировки на русском и кыргызском и необязательный номер зала. Сохраните расписание: посетители увидят его отдельно на странице бокса, борьбы или фитнеса.

## 4. Настройте ссылки восстановления пароля

В **Authentication → URL Configuration** добавьте адрес опубликованного сайта в **Site URL** и **Redirect URLs**. Для локальной проверки можно добавить `http://localhost:5500/**` и открыть сайт через локальный сервер, например Live Server. Восстановление пароля по `file://` не поддерживается.

Для сброса пароля открывайте сайт по HTTP(S), не через `file://`. Добавьте точный опубликованный адрес сайта с путём `#password-reset` в разрешённые **Redirect URLs**. Для локальной проверки добавьте `http://localhost:5500/**` и откройте сайт через Live Server; восстановление через `file://` браузер блокирует.

Для надёжной отправки писем посетителям настройте свой SMTP-сервис в параметрах Authentication. У тестовой почтовой отправки Supabase есть ограничения. При ошибке отправки проверьте **Authentication → Logs**.

## 5. Откройте сайт через HTTP

Запускайте сайт через локальный сервер или опубликуйте его на статическом хостинге. После настройки файл `supabase-config.js` должен поставляться вместе с `index.html`, `script.js` и `styles.css`.

Изменения цен и товаров сохраняются в общей базе Supabase; фотографии загружаются в публичное хранилище Supabase Storage. Фото товара необязательно: его можно добавить без фото, и он всё равно появится в магазине с заглушкой. Если загружаете фото, допустимы JPEG, PNG или WebP до 5 МБ. При редактировании можно оставить существующее фото или загрузить новое. При удалении товара его фото также удаляется из хранилища. Корзина остаётся локальной для посетителя.

## Бесплатный тариф

На момент подготовки настройки Supabase указывает бесплатный план с лимитами, включая 500 МБ базы данных и 1 ГБ файлового хранилища. Бесплатные проекты могут приостанавливаться после недели бездействия; условия и лимиты могут меняться. Проверьте [актуальные цены Supabase](https://supabase.com/pricing).
